# qudog.ru

Лендинг ПО Qubot и роботов-собак. Статика на GitHub Pages: любой коммит в `main` сразу выходит на сайт. Сборки нет, файлы можно править прямо в веб-редакторе GitHub. Для просмотра локально: `python3 -m http.server` в корне.

## Что где менять

| Что | Где |
|---|---|
| Тексты и порядок блоков | `index.html`, блоки разделены комментариями `<!-- ===== -->` |
| Цены роботов | `index.html`, блок «РОБОТЫ», `.robot__price` |
| Лицензии, аренда, станция, пилот | `index.html`, блок «ЦЕНЫ» |
| Дата действия цен | `index.html`, поиск по «17 ноября», два места |
| Новый кейс | `index.html`, блок «КЕЙСЫ», скопировать `<li class="case">`. Сетка рассчитана на чётный ряд: последние две карточки растянуты |
| Отчёт о миссии | заменить `public/docs/mission-report-zsm-1.pdf`, цифры и таймлайн в блоке «ПРИМЕР МИССИИ» |
| Документы испытаний | `public/docs/pmi-*.pdf` |
| Фото команды | `public/images/photos/team-768.webp`, `team-1280.webp` |
| Цвета, шрифт, радиусы | `public/css/tokens.css` |
| Письмо из формы | `public/js/main.js` |

## Файлы

```
index.html
public/css/tokens.css      цвета, шрифт, радиусы (значения сняты с qubot.ru)

public/css/components.css  кнопки, шапка, таблицы, форма, подвал
public/css/sections.css    секции в порядке index.html
public/js/main.js          шапка, меню, видео-петли, письмо из формы
public/images/             photos, robots, ui, mission, posters
public/video/              ролики
public/docs/               PDF для скачивания
public/fonts/              Wix Madefor Display (OFL)
```

## Видео

GitHub не принимает файлы больше 100 МБ, поэтому длинные ролики лежат в двух версиях: AV1 для новых браузеров и H.264 для остальных. Новый ролик:

```bash
ffmpeg -i in.mov -vf fps=30 -c:v libx264 -preset slow -b:v 5800k -maxrate 11600k -bufsize 23200k \
  -pix_fmt yuv420p -c:a copy -movflags +faststart out.h264.mp4
```

## Документы

Копии в `public/docs` отличаются от исходников: в ПМИ убраны контактные данные представителей, в отчёте о миссии убраны название карты и служебная строка с моделью и стоимостью анализа, во всех PDF очищены метаданные. Перед заменой документа проверьте, что в новом файле этого тоже нет.

Форма не отправляет данные сама: на GitHub Pages нет сервера, поэтому она открывает черновик письма на info@qubot.ru.
