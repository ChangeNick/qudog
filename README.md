# Qubot — версия с отдельными медиафайлами

Откройте index.html в браузере. Для передачи сайта отправляйте всю папку или ZIP: index.html использует файлы из public.

Структура:
- index.html — разметка страницы;
- public/styles.css — оформление;
- public/app.js — интерактивность;
- public/models.js — модели, цены и ссылки;
- public/contact-mail.js — подготовка письма из формы;
- public/images/ — фотографии, логотип и постеры;
- public/video/ — два видеоролика;
- public/fonts/ — Wix Madefor Display и лицензия шрифта;
- public/docs/ — исходный PDF кейса кампуса.

В HTML нет base64, встроенных стилей или JavaScript. Интерактивная SVG-схема маршрута сохранена как разметка интерфейса. Скрипты подключены обычными defer-тегами и не требуют Node.js или ES-модулей. Все пути относительные: версия подходит и для размещения в подпапке сайта.

Форма подготавливает письмо в почтовой программе посетителя. Чтобы передать заявку, письмо нужно отправить самостоятельно. Кнопки моделей ведут на соответствующие страницы qubot.ru. PDF кейса скачивается из public/docs.

Для GitHub Pages загрузите index.html и всю папку public в корень репозитория. Изменение публичности выполняется отдельно — этот архив ничего не публикует.
